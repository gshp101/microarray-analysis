# PathRx app icon options

Candidate icons for the desktop app (`options.png` shows each at several sizes, on light
and dark backgrounds). Each is an SVG with a 512 px PNG beside it. The one in use is copied to
`src/pathrx/desktop/icons/pathrx.svg` and `pathrx.png`.

1. **Array grid**: microarray spots (red up, blue down) with a pathway threading the up spots.
2. **Pathway network**: a small metabolic network with the affected route highlighted.
3. **Volcano**: a volcano plot, with the top hit circled.
4. **Helix and capsule**: expression to treatment, on a light tile.
5. **Route to target**: a winding pathway from a changed gene to a drug target.

Combinations of 1 and 4 (array grid and capsule):

6. **Grid and capsule**: the array grid with a capsule laid over its corner (the app icon; also `icon.png` at the repo root).
7. **Path into capsule**: the pathway through the up spots leads down into a capsule.
8. **Capsule of spots**: a capsule whose clear half holds array spots.
