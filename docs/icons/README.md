# PathRx app icon options

Five candidate icons for the desktop app (`options.png` shows each at several sizes, on light
and dark backgrounds). Each is an SVG with a 512 px PNG beside it. The one in use is copied to
`src/pathrx/desktop/icons/pathrx.svg` and `pathrx.png`.

1. **Array grid**: microarray spots (red up, blue down) with a pathway threading the up spots.
2. **Pathway network**: a small metabolic network with the affected route highlighted (current default).
3. **Volcano**: a volcano plot, with the top hit circled.
4. **Helix and capsule**: expression to treatment, on a light tile.
5. **Route to target**: a winding pathway from a changed gene to a drug target.
